# シーン別の構成レシピ

> STEP 1 で「どんな場面で使う資料か」を決めたら、ここから近いレシピを1つ選び、**型の並びを出発点にして** STEP 2 の構成表を作る。
> レシピは目安。台本に無い要素（数字・声・料金）の枚は**作らずに飛ばす**（空の枚・作り話は禁止）。
> 枚数は台本の量で決める。1枚＝言いたいこと1つ。

## シーンの選び方
| 台本・依頼の様子 | シーン |
|---|---|
| 相手に買う・導入する・契約する判断をしてほしい | A. 営業提案・サービス説明 |
| 人前で教える・講座・勉強会・ウェビナー | B. セミナー・講座 |
| 会社や組織を知ってもらう・人を集める | C. 会社説明・採用 |
| 上司・チーム・取引先に結果と次の手を伝える | D. 社内報告・定例 |
| 出資・融資・社内決裁で「やる価値」を通す | E. 事業計画・ピッチ |
| 日時・場所があって参加してほしい | F. イベント・募集告知 |
| 手順を覚えて同じようにやってほしい | G. 研修・マニュアル |
| 事例・インタビュー・登壇の話を伝える | H. 事例紹介・講演 |

---

## A. 営業提案・サービス説明
**相手が知りたい順**: 自分の困りごと → どう変わる → 本当にできる？ → いくら・どう進む → 次に何をする
| # | 型 | 中身 |
|---|---|---|
| 1 | cover | 相手の得が読めるタイトル |
| 2 | agenda | 3〜4章 |
| 3 | section | 章1: いまの困りごと |
| 4 | problem / bars / funnel | 困りごとを数字で（数字が無ければ problem） |
| 5 | message | 解決の方針を一文で（暗い面） |
| 6 | section | 章2: 仕組みと効果 |
| 7 | flow | 使い方・仕組みの流れ |
| 8 | compare | 導入前 → 導入後 |
| 9 | big-number | 効果の数字（台本にあるときだけ） |
| 10 | testimonial / stats | 導入実績・お客様の声（あるときだけ） |
| 11 | features | 安心材料・決めごと（3つ） |
| 12 | section | 章3: 料金と進め方 |
| 13 | pricing / table | 料金・プラン比較 |
| 14 | timeline | 導入スケジュール |
| 15 | faq | 導入前の不安（あれば） |
| 16 | closing | 次の行動を1つ |
- テーマ: fresh / corporate / duotone ／ 見本: `examples/inquiry-ai-proposal/`

## B. セミナー・講座
**聞き手の頭の動き**: 自分ごと化 → 考えてみる → 教わる → 手を動かす → 持ち帰る
| # | 型 | 中身 |
|---|---|---|
| 1 | cover | 講座名＋受けると何ができるようになるか |
| 2 | profile | 講師紹介（肩書き・実績は事実だけ） |
| 3 | agenda | 今日の流れ |
| 4 | question | 最初の問いかけ（手を挙げる・考える時間） |
| 5 | problem / bars | なぜ今これが必要か |
| 6 | section | 章ごとに1枚 |
| 7 | pyramid / matrix / flow | 考え方の枠組み（図で覚えてもらう） |
| 8 | compare | よくある間違い → 正しいやり方 |
| 9 | quote | 印象に残る言葉（出典がある引用だけ） |
| 10 | question | ワーク（時間・やること） |
| 11 | checklist | 明日からやることのチェックリスト |
| 12 | summary | 今日のまとめ |
| 13 | closing | 次の講座・相談・アンケート |
- 章ごとに「section → 図解 → question（ワーク）」を1セットにすると単調にならない
- テーマ: pop（SNS・初心者向け）/ corporate（経営者向け）/ warm（ワークショップ）

## C. 会社説明・採用
| # | 型 | 中身 |
|---|---|---|
| 1 | cover / photo | 会社名＋一言で何をしている会社か |
| 2 | message | 理念・ミッション（暗い面） |
| 3 | stats | 数字で見る会社（社員数・創業・拠点・顧客数など3〜4個） |
| 4 | spec | 会社概要（社名・所在地・設立・代表・事業内容） |
| 5 | features | 事業・サービスの柱（3〜4） |
| 6 | timeline | 沿革 |
| 7 | team | メンバー紹介（2〜4人） |
| 8 | photo | 働く現場の写真（実物があるときだけ） |
| 9 | testimonial | 社員の声（本人の許可があるときだけ） |
| 10 | timeline | 1日の流れ（採用） |
| 11 | table / spec | 募集要項・待遇 |
| 12 | faq | 応募前によくある質問 |
| 13 | closing | 応募・説明会の申し込み |
- テーマ: fresh（採用）/ corporate（会社案内）/ dynamic（ビジョン重視）

## D. 社内報告・定例
**結論が先**。報告を聞く人は「で、どうする？」を知りたい
| # | 型 | 中身 |
|---|---|---|
| 1 | cover | 報告名＋期間 |
| 2 | message | 結論を一文で（目標に届いた／届かない、次の一手） |
| 3 | stats | 主要な数字3〜4個（目標との差も） |
| 4 | bars（column） | 推移（月別など） |
| 5 | compare / table | 目標 vs 実績、前月 vs 今月 |
| 6 | problem | うまくいかなかった理由（2〜3） |
| 7 | matrix | 次の打ち手の優先順位 |
| 8 | table | 次のアクション（何を・誰が・いつまで） |
| 9 | closing | 決めてほしいこと（承認・判断） |
- 社内向けは agenda・section を省いてよい（10枚以下なら事前チェックの注意だけで止まらない）
- テーマ: corporate / minimal

## どのシーンでも共通
- 16:9 以外（SNS正方形・縦型・動画のワイプ付き）はこの型エンジンでは未対応。必要なら依頼時に伝え、旧ルートで作る
- お客様の声・写真・ロゴ・実名は、使ってよいと確認が取れたものだけ
