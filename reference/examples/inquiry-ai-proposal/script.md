# 台本（見本・架空の医療機関向け提案。数字はすべて架空）

問い合わせ対応をAIで半分にする、という提案です。

いま受付の方は、月に80時間くらいを問い合わせの返信に使っています。中身を数えると、よくある質問が48時間、予約の変更が18時間、料金の確認が9時間、その他5時間。つまり6割は同じ質問への返信です。
月300件の問い合わせのうち、当日中に返信できているのは120件。予約につながるのは45件で、返信が翌日になると離脱が増えます。

やり方はシンプルで、メールとLINEを1か所に集めて、AIが質問集をもとに下書きを作り、受付の方が確認して送るだけ。新しい質問は月1回まとめて質問集を育てます。
大事な方針は「AIは下書き係。送るのは人が決める」です。AIが自動で送ることはしません。

これで返信の手間は80時間から40時間くらいまで減る見込みです。閉院後にまとめて返信していたのが、下書きを確認して送るだけになり、返信漏れも一覧で見えるようになります。

安全のために、問い合わせ内容はAIの学習に使わない、送信は必ず人、誰がいつ送ったか記録を残す、の3つを守ります。

進め方は3か月。1か月目に過去の問い合わせから50問の質問集を作り、2か月目に受付1名・1日10件で下書きを試し、3か月目に全員で使います。

料金は、設定代行が初回のみ50,000円（税込）、3か月伴走するプランが月30,000円（税込）。伴走は月ごとの契約なので翌月から止められます。

まずは30分、いまの問い合わせの量を一緒に数えるところから始めませんか。
