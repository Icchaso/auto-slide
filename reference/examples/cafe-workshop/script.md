# 台本（見本・架空のカフェ向けワークショップ告知。数字はすべて架空）

カフェの店長さん向けに「スマホ1台で新メニューの写真が売れる写真になる」ワークショップを開きます。

お店の悩みは3つ。写真が暗くておいしそうに見えない、撮る時間がない、何を載せればいいか分からない。

去年のお客様アンケートで「来店のきっかけ」を聞いたら、Instagramが38%、Googleマップが27%、口コミが21%、通りがかりが14%でした。写真で選ばれています。

撮り方は3つだけ覚えれば十分です。一番大事なのは窓際の光。その上に、真上か45度の角度。最後に、手や湯気など動きを入れる。

前回参加した店長さんは「撮影が5分で終わるようになって、新メニューの投稿がいいね3倍になりました」と話してくれました（掲載許可あり）。

内容は2時間。前半で撮り方、後半で自分のお店のメニューを実際に撮って、その場で直します。参加費は1人5,500円（税込）、定員8名。

よくある質問：一眼レフは要りません、スマホだけで大丈夫。写真が苦手でも大丈夫、1人ずつ見ます。

まとめると、光・角度・動きの3つを覚えれば、スマホでも選ばれる写真が撮れます。申し込みはLINEからどうぞ。
